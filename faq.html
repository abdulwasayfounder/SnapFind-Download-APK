Frequently Asked Questions

Everything you need to know about indexing, search capabilities, Vault protection, APK installation, and privacy.

SnapFind AI is a dedicated visual memory engine for Android. It monitors your device for newly captured screenshots, extracts text via OCR, organizes them into Smart Snaps collections (Banking, Receipts, Travel, Work), and enables lightning-fast natural language search.
Search combines two complementary systems: (1) exact tokenized OCR text matching for dates, numbers, currency amounts, and codes; and (2) semantic intent matching that understands conversational phrases like “my python code snippet” or “boarding pass for flight”.
Yes. SnapFind uses high-accuracy Optical Character Recognition (OCR) to read visible text across diverse apps, whether it is terminal logs, bank statements, chat messages, or receipt lines.
Yes. If a screenshot contains a readable QR code (such as a Wi-Fi share or event ticket) or visible website URLs (https://...), SnapFind decodes the link, allowing you to copy the URL or open it in your browser with one tap.
Yes. SnapFind features a dedicated locked Vault. Screenshots placed in the Vault are omitted from standard photo pickers, thumbnails, and unauthenticated searches.
Yes. You can toggle Collection Lock on any Smart Snap category (such as Banking & Payments or Private & Sensitive) to require device biometric verification (fingerprint, face unlock) or PIN entry before viewing the contents.
Yes. The app compares perceptual image hashes. If you take multiple burst screenshots of the identical screen, SnapFind only indexes one canonical copy, saving storage and keeping results uncluttered.
Local detection, duplicate checking, Vault authentication, and search against previously indexed local captures operate completely offline. Cloud-dependent deep semantic analysis queues safely until an internet connection is re-established. We never falsely claim that cloud AI operates without internet.
Download the APK from the official GitHub Releases page. In Android Settings, enable “Install unknown apps” for your browser, tap the downloaded file in your notification bar or Downloads folder, and select “Install”. A detailed step-by-step walkthrough is available on our Support Page.
Updates are posted directly to the official GitHub repository releases tab. When a new version is published, you can download the updated APK and install it over your existing installation without losing your indexed screenshots.
